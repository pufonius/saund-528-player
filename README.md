# Sound528 — Audio Player MVP

Минималистичный веб-плеер для генерации звука на частоте 528 Гц. Предназначен для релаксации, снижения уровня стресса и повышения концентрации во время работы и учебы.

## Функционал MVP (в разработке):
- Генерация чистого тона 528 Гц в реальном времени (Web Audio API)
- Регулировка громкости
- Таймер автоотключения
- Простой и адаптивный UI

## Стек технологий:
- HTML5 / CSS3
- JavaScript (Web Audio API)
- Git / GitHub Pages
